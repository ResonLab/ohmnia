Installer Ohmnia sur Linux

Pas à pas, sans rien supposer. Si vous n'avez jamais installé de programme sur Linux, cette page est faite pour vous : il n'y a aucune commande à taper.

La version Linux n'est pas encore publiée. Cette page décrit la marche à suivre pour le jour où elle le sera. En attendant, seule la version Windows est disponible au téléchargement.

Lequel des deux fichiers prendre

Deux fichiers seront proposés. Ils installent la même application : seule la manière de la ranger sur votre ordinateur change.

Le fichier .deb Si vous êtes sur Ubuntu, Linux Mint, Debian ou Pop!_OS. C'est le plus simple : Ohmnia s'installe comme un programme normal et apparaît dans votre menu d'applications.
Le fichier .AppImage Pour toutes les autres (Fedora, Manjaro, openSUSE, Arch…), ou si le .deb refuse de s'installer. C'est un fichier unique qui se lance directement, sans rien installer.

Vous ne savez pas quel Linux vous avez ? Prenez le .AppImage : il fonctionne partout.

Avec le fichier .deb

  1. Téléchargez le fichier qui se termine par .deb depuis la page de téléchargement. Il arrive dans votre dossier Téléchargements.
  2. Double-cliquez dessus. Une fenêtre d'installation s'ouvre. Si rien ne se passe : clic droit sur le fichier → Ouvrir avec → Installation de logiciels.
  3. Cliquez sur Installer, puis saisissez le mot de passe de votre session quand il vous est demandé. C'est normal : installer un programme demande votre autorisation.
  4. Ouvrez votre menu d'applications et cherchez Ohmnia. C'est fini.

Avec le fichier .AppImage

Un AppImage est un fichier unique qui contient tout le programme. Il ne s'installe pas : vous le rangez où vous voulez et vous le lancez. Une seule étape est un peu inhabituelle — il faut dire à Linux que ce fichier a le droit de s'exécuter. C'est une sécurité, elle se règle en trois clics.

  1. Téléchargez le fichier qui se termine par .AppImage.
  2. Rangez-le où vous le retrouverez — votre dossier personnel, ou un dossier Applications que vous créez. Évitez de le laisser dans Téléchargements, où vous risquez de le supprimer par mégarde.
  3. Clic droit sur le fichier → Propriétés → onglet Permissions, puis cochez Autoriser l'exécution du fichier comme un programme. Fermez la fenêtre. Selon votre version de Linux, la case peut s'appeler « Exécutable » ou « Autoriser l'exécution ». C'est la même chose.
  4. Double-cliquez sur le fichier. Ohmnia s'ouvre.

Si quelque chose ne va pas

Je double-clique sur l'AppImage et il ne se passe rien

La case d'exécution n'est pas cochée. Reprenez l'étape 3 ci-dessus : clic droit → Propriétés → Permissions.

Un message parle de « FUSE » ou de « libfuse »

Il manque un composant que certaines versions récentes de Linux ne fournissent plus d'origine. Ouvrez votre logithèque, cherchez libfuse2 et installez-le, puis relancez. Si vous préférez éviter, prenez le fichier .deb à la place.

Le .deb refuse de s'installer

Votre version de Linux n'utilise probablement pas ce format. Prenez le fichier .AppImage, qui fonctionne partout.

Ohmnia n'apparaît pas dans mon menu après le .deb

Déconnectez-vous puis reconnectez-vous à votre session : le menu se reconstruit à ce moment-là.

Où sont vos données sur Linux

Comme sur Windows, tout reste sur votre ordinateur. Vos données sont rangées dans un dossier caché de votre dossier personnel :

~/.config/Ohmnia

Pour le voir dans votre gestionnaire de fichiers, appuyez sur Ctrl + H — cela affiche les dossiers cachés. Vous n'avez normalement aucune raison d'aller y toucher à la main : passez plutôt par Paramètres de l'app dans Ohmnia, qui sait ouvrir ce dossier pour vous et faire vos sauvegardes.
